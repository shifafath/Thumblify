# Thumblify

An AI-powered web application that helps users generate attractive YouTube thumbnails by providing a title, style, color scheme, and additional prompts.

## Features

- AI-generated thumbnail creation
- Multiple thumbnail styles
- Different aspect ratio options
- Color scheme selection
- User authentication
- Save generated thumbnails
- Cloudinary image storage

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- MongoDB
- Mongoose

### Other Tools
- GEMINI API

## Installation

Clone the repository:

```bash
git clone https://github.com/shifafath/Thumblify.git
```

Go to the project folder:

```bash
cd Thumblify
```

Install dependencies:

```bash
npm install
```

Run the frontend and backend servers.
